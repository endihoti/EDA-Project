
# Exploratory Data Analysis (EDA) Project

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) to uncover patterns, anomalies, relationships, and key statistical insights within the dataset. Through data cleaning, statistical summary, and visual exploration, this analysis establishes baseline data quality and identifies key drivers in the underlying data.

---

## Technical Highlights & Methodologies

* **Data Cleaning & Preprocessing:** Identified and addressed missing values, duplicates, out-of-range values, and inconsistent data types.
* **Univariate Analysis:** Analyzed single-variable distributions using histograms, box plots, and descriptive statistics to understand central tendencies and spread.
* **Bivariate & Multivariate Analysis:** Evaluated feature relationships and target correlations using scatter plots, correlation heatmaps, and categorical bar charts.
* **Outlier Detection:** Used boxplots and IQR (Interquartile Range) methods to detect and evaluate influential outliers.

---

## Exploratory Findings & Visualizations

* **Distribution Assessment:** Evaluated skewness across numerical features to determine necessary data transformations.
* **Correlation Insights:** Identified key features strongly correlated with primary outcome variables using correlation heatmaps.
* **Group Comparisons:** Analyzed sub-group behavioral differences across categorical segments using aggregated metrics and visual charts.
